## 从这段里能读到什么

**26 句台词 / 14 个玩家回合，其中 14 句前面没有玩家发言** —— 她在自己维持对话。
房间的第一条消息（`sequence=1`）就是她的问候，玩家一个字还没打。

**回复不是请求的函数**：连续两个玩家回合（`别` + `告诉我`）换来一句回复；
而一个玩家回合能引出多句（13.11 争论之后她先说「咦？不对…」再说「我脑子有点乱，咱们换个题吧。」）。

**"（认真）" 这类前缀是客户端渲染的情绪标注**，所以它们以字面文本留在日志里。

**归属必须说清**：在整份捕获里，`npc_id=14` 用过、且**只用过** `（认真）`（×2）。
其余标注出现在同场捕获里，但**不属于她** —— 逐个查过 `npc_id`：

| 标注 | 归属 |
|---|---|
| `（认真）` | **npc#14（娜洛）×2** + npc#80003 ×2 |
| `（自言自语）` | npc#80008（街头环境 NPC） |
| `（望天）` | npc#80008 |
| `（清清嗓子）` | npc#80008 |
| `（兴奋）` | npc#80003 |
| `（鼓励）` | npc#80003 |

它们证明**这套标注系统存在**，不证明**她使用更多标注**。
扮演娜洛时，除 `（认真）` 之外不要用别的标注 —— 那会变成街头 NPC 的味道。

**四件只有带上下文的 LLM 才做得出的事**：

1. 昵称记忆：`+99860` 一次提及 → `+124656` / `+512125` 两次复述，中间没有任何重复提示
2. 服装感知：`+45500` 的开场白来自 `3749 LLMUpdateOutLookReq` 的 `desc` 字段
   （字面文本，例如 `"络米新星拼接袜:rank1,黑色,白色,袜子,毛线,运动;…"`）
3. 可恢复的错误：答错 → 被指出 → 降级 → 稍后自己改对，并带情绪解释
4. **跨会话记忆**：2026-09-23 的另一次会话里，她自己重提了前一天的数学题 ——
   「当然记得，你上次出的数学题，我到现在还记得！」「那道题还让我出丑了，你可别得意～」
   「（认真）13.8更大，我这次不会再被你耍啦！」
